# Yonis Radio - محطاتك المفضلة

تطبيق Android للاستماع إلى محطات عربية مباشرة، مع بحث وتصنيفات ومفضّلة ومشغّل صغير. يظل الصوت قادرًا على العمل عند الانتقال إلى تطبيق آخر أو إطفاء الشاشة، وتظهر بيانات المحطة وأزرار الوسائط على شاشة القفل والإشعار في Android عند منح صلاحية الإشعارات.

## قائمة المحطات

يوجد الكتالوج الكامل في `shared/radio-stations.ts` ويُستخدم كقائمة مضمّنة حتى يعمل التطبيق دون اتصال بخادم الكتالوج. تُحمّل النسخة الجديدة القائمة من قاعدة بيانات المشروع أولًا، ثم تستخدم النسخة المضمّنة عند تعذّر الاتصال. ملفات Windows المرفقة تحتوي على القائمة نفسها داخل التطبيق.

## إضافة محطة مستقبلًا

أضف سجلًا جديدًا إلى مصفوفة `RADIO_STATIONS` في `shared/radio-stations.ts` مع `id` فريد واسم المحطة والتردد إن وجد والتصنيف ورابط بث HTTPS مباشر. حدّث `sortOrder` ليظهر السجل في مكانه، وحدد `origin` بدقة (`official` لرابط ناشر المحطة، أو `directory` لرابط موثوق فُحص، أو `community` للبث المجتمعي). لا تستخدم صفحة ويب عادية كرابط بث. اختبر الرابط كاستجابة صوتية؛ في البث المجتمعي اذكر ذلك في الاسم والحالة. بعد تحديث مصدر Windows وإعادة البناء، أرسل التطبيقين للمستخدمين كتحديثين منفصلين.

لإضافة محطة جديدة من غير التعامل مع ملفات المشروع، أرسل اسم المحطة أو رابط بثها وسأجهّز تحديثًا جديدًا للكمبيوتر وAndroid.

## ملفات Android

ملف `eas.json` يحتوي ملف بناء `preview` لتوزيع داخلي بصيغة APK قابلة للتثبيت مباشرة. بناء Android الأصلي النهائي يتم من لوحة المشروع بعد حفظ نقطة التحقق؛ معاينة Expo Web لا تُعد ملف تثبيت Android.
